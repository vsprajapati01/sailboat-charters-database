# San Juan Sailboat Charters — Database System

**Database Systems coursework project** — a complete relational database for a sailboat charter business, built in Microsoft Access to replace a spreadsheet-based system.

## What it does
A working database for managing boats, owners, customers, and charters:
- **Normalized tables (3NF)** — entities, relationships, and integrity constraints designed to eliminate redundancy
- **Data-entry forms** — user-friendly forms for boats, owners, customers, and charters
- **SQL queries** — flexible data retrieval and analysis (charter history, owner/boat lookups, business metrics)
- **Automated reports** — Charter Customer Report and Boat Owner Report for business insights

## My role: Data Architecture (6-member team)
- Database structure design and normalization (1NF → 3NF)
- Data integrity rules and relationship enforcement
- Data migration planning from the legacy spreadsheet system
- Structural optimization and accuracy validation
